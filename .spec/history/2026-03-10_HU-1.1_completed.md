# Objective: HU-1.1 — Navegacion mobile-first y estructura base de experiencia

## Context

- **Feature:** FEAT-1 — Foundation mobile-first de catalogo y navegacion
- **Story:** Como residente de obra que navega desde celular, quiero una navegacion clara y consistente entre Home, Catalogo, Nosotros y Contacto, para poder moverme rapido entre secciones sin perder contexto.
- **Spec Level:** Lite
- **TDD Mode:** flexible
- **Git Strategy:** trunk (work continues on `main`)
- **Estimated Duration:** 2h 30m

## Acceptance Criteria (BDD)

### Scenario 1: Navegacion principal accesible en mobile

- **Dado que:** Estoy en un dispositivo movil.
- **Cuando:** Abro el menu principal.
- **Entonces:** Debo ver todas las rutas clave y poder navegar con maximo dos toques.

### Scenario 2: Persistencia de contexto de ruta activa

- **Dado que:** Estoy en cualquier pagina del sitio.
- **Cuando:** Visualizo el encabezado o menu.
- **Entonces:** Debe resaltarse claramente la seccion activa.

### Scenario 3: Manejo de error para ruta invalida

- **Dado que:** Ingreso una URL inexistente.
- **Cuando:** El sistema intenta resolver la ruta.
- **Entonces:** Debe mostrar una pantalla 404 con opcion para regresar a Home y Catalogo.
